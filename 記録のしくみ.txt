きょうのKOKOいろ　記録のしくみ（何色が選ばれたかを数える）
============================================================

いまは「止まった状態」で入っています。
assets/stats.js の STATS_URL が空なので、通信はひとつも起きません。
下の手順でスプレッドシートを作り、そのURLを入れた時点から数え始めます。


■ 何を記録するか

  日時 … 記録した側で付ける（端末の時計はずれていることがあるため）
  できごと … open（ページが開かれた）／ choose（色が決まった）
  Ver … top ／ personal ／ business ／ kids
  色 … 決まった色の名前（choose のときだけ）
  通し番号 … このブラウザに振った番号。誰かは分からない。
  LINE … LINEの中から開かれたか
  場所 … ホームページの中か、直接開かれたか

名前・連絡先・端末そのものの番号は、扱いません。
IPアドレスも、こちらのスプレッドシートには残りません。


■ 手順1　スプレッドシートを作る

Googleスプレッドシートを新しく作り、名前を「きょうのKOKOいろ記録」などにします。
1行目に、左から順にこの見出しを入れてください。

  日時 / できごと / Ver / 色 / 通し番号 / LINE / 場所


■ 手順2　記録するプログラムを入れる

そのスプレッドシートで
  拡張機能 → Apps Script
を開き、出てきたコードを全部消して、下をそのまま貼ります。

----------------------------------------------------------------
function doGet(e) {
  var p = (e && e.parameter) || {};

  /* 同じ瞬間に2人が来ても、行が壊れないようにする */
  var lock = LockService.getScriptLock();
  try { lock.waitLock(5000); } catch (err) { return ok(); }

  try {
    SpreadsheetApp.getActiveSheet().appendRow([
      new Date(),
      p.e     || '',
      p.ver   || '',
      p.color || '',
      p.id    || '',
      p.line  === '1' ? 'LINE' : '',
      p.embed === '1' ? 'ホームページ' : '直接'
    ]);
  } finally {
    lock.releaseLock();
  }
  return ok();
}

function ok() {
  return ContentService.createTextOutput('ok');
}
----------------------------------------------------------------

保存します（フロッピーのマーク）。


■ 手順3　公開して、URLをもらう

  右上の「デプロイ」→「新しいデプロイ」
  歯車のマーク →「ウェブアプリ」を選ぶ
  説明 … なんでもよい（例：きょうのKOKOいろ記録）
  次のユーザーとして実行 … 自分
  アクセスできるユーザー … 全員          ← ここが大事
  「デプロイ」を押す

初回は「承認が必要です」と出ます。
  アクセスを承認 → 自分のGoogleアカウントを選ぶ
  「このアプリはGoogleで確認されていません」と出たら
  → 詳細 →（プロジェクト名）に移動 → 許可

最後に出る
  https://script.google.com/macros/s/……/exec
これがURLです。コピーしてください。


■ 手順4　URLを入れる

assets/stats.js の7行目あたり

  KI.STATS_URL = '';

の '' の中に、さきほどのURLを貼ります。

  KI.STATS_URL = 'https://script.google.com/macros/s/……/exec';

HTMLの中の ?v=…… （版の番号）も一緒に新しくしてください。
これを変えないと、見ている人のブラウザが古いものを使い続けます。


■ 手順5　動いているか確かめる

ページを開いて、色をひとつ選びます。
スプレッドシートに2行増えていれば成功です。

  1行目 … open
  2行目 … choose と、選んだ色

増えないときは、手順3の「アクセスできるユーザー＝全員」を見直してください。
ここが「自分のみ」になっていると、他の人からは記録できません。


■ 止めたいとき

  KI.STATS_URL = '';

に戻すだけです。通信はその場で止まります。


■ 直したあとに毎回やること

スプレッドシートの中身を見るだけなら、何もしなくて大丈夫です。
stats.js を直したときだけ、HTMLの ?v=…… を変えてください。


■ お客さんへの説明

ホームページの、このツールの近くに一文あると安心です。

  このページで選ばれた色は、協会の改善のためだけに記録しています。
  お名前など、個人を特定する情報は記録していません。
