# きょうのいろ — 今日の色 きせかえツール

「今日はどんな自分でいたいか」を選ぶと、そう見せてくれる色を1つ提案し、
その色を身のまわりにどう取り入れるかを、キャラクターの絵と一緒に出すツールです。

FTA色彩心理®︎（KOKOIROメンタルケア協会）の講座に来てもらうための入口として作っています。
**講座の特典として配る想定なので、作り込みすぎない**のが方針です。

**外部への通信はありません。** 文章はすべて固定で、APIキーもサーバーも要らない、
ビルド不要の静的サイトです。ファイル一式をどこかに置けばそのまま動きます。

公開先: https://ikkonikkoniko-star.github.io/kyounoanata/

## 画面

| ファイル | 内容 |
|---|---|
| `index.html` | 3つのVerへの入口。キャラクターの顔を出して選んでもらう |
| `personal.html` | 個人Ver |
| `business.html` | ビジネスVer |
| `kids.html` | キッズVer |

見た目は3Ver共通で、差分は `assets/versions.js` にまとまっています。

## 色の決まり方

**色はチップを押した時点で決まります。** `assets/colors.js` の1行が1色で、
どのチップがどの色になるかは固定。判定も推論もしません。同じチップを押せば必ず同じ結果が出ます。

色名は身近で、そのまま口に出せる名前だけ。表記はひらがな中心で、
カタカナでしか通じない色だけカタカナのままです。和色などの珍しい名前は入れていません。

全17色。個人Verだけ、ゴールドが日常の気持ちになじまないので出していません（`hideColors`）。

## 結果カードの中身

| 行 | 中身 | どこで直すか |
|---|---|---|
| 一言 | きょうは○○のちからをかりてみましょう。 | `versions.js` の `resultFor`（キッズだけ `message` で上書き） |
| 取り入れ方 1〜2文目 | 着る服に○○を取り入れてみたり、…… | `versions.js` の `suggestion`（キッズは出さない） |
| 色の意味 | ○○は（意味） | `colors.js` の `meaning`（ビジネスとキッズは `versions.js` の `texts` で上書き） |
| 締めの一文 | （締めの一文） | `colors.js` の `closing`（同上） |

Verごとに言い回しを変えたいときは `versions.js` に足します。`texts` を持たないVerは
`colors.js` の文言をそのまま使います。

| Ver | 文章のトーン |
|---|---|
| 個人 | 日常のことば。服と小物への取り入れ方を出す |
| ビジネス | 仕事の場面のことば。服と小物への取り入れ方を出す |
| キッズ | ひらがな。**服と小物の話はせず、色の説明だけ** |

## イラストの仕様

viewBox は 340x300。人物を中央に、左右に小物を単体で置きます。人物は小物を身につけません。

| Ver | 左 | 中央 | 右 |
|---|---|---|---|
| 個人 | ハンカチ（金銀のときは腕時計） | Tシャツ＋デニム | バッグ |
| ビジネス | 腕時計 | Tシャツ＋ジャケット | ペン |
| キッズ | 靴下（金銀のときはトレーディングカード） | Tシャツ＋クロップドパンツ | ハンカチ（金銀のときはメダル） |

- **色が変わるのはTシャツだけ。** デニムとジャケットは固定色
- **ゴールドとシルバーのときはTシャツを塗りません。** 小物だけが金属色になります
  （金属の服は着るものとして絵にならず、文章のほうも「服ではなくアクセサリーと小物に」と言っているため）
- 個人とビジネスは同じ等身。キッズは頭の大きい丸い等身
- 髪は左右対称のまるい形。男女どちらにも見えないようにという要望でこうなっています

## 動かす

```
python3 -m http.server 8000
# → http://localhost:8000/
```

`index.html` をブラウザで直接開くだけでも動きます（外部への通信がないため）。

## 公開と貼り付け

GitHub Pages で公開しています。設定は Settings → Pages で
Source を「Deploy from a branch」、Branch を `claude/kyou-no-iro-tool-p21vu4` の `/ (root)`。
**このブランチに push するたびに自動で作り直されます。** 貼り直す作業はありません。

他のサイトに載せるときは、リンクを貼るか、下の1行を埋め込みます。

```html
<iframe src="https://ikkonikkoniko-star.github.io/kyounoanata/"
        style="width:100%;height:900px;border:0" title="きょうのいろ"></iframe>
```

LINE公式アカウントで配る場合も、この URL をリッチメニューに設定すれば
LINEのアプリ内ブラウザで動きます。LIFF は不要です。

## ファイル構成

```
assets/
  colors.js      17色パレット（気持ち・色名・hex・意味・締め）とチップの組み立て
  character.js   Verごとのキャラクター・小物のSVG描画、色の濃淡計算、顔だけの描画
  versions.js    3Verの差分（質問文・チップ文言・説明文・取り入れ方）と結果の組み立て
  app.js         画面の組み立てと操作
  style.css      3Ver共通のスタイル
きょうのいろ_17色.docx   配布用（文章だけ）。いまは使っていない
```

## 保留していること

- **配布用のワード**（`きょうのいろ_17色.docx`）は一旦なしになりました。中身は
  個人Verの文言のままで、最新の修正は反映していません。
- 色の意味と締めの一文のうち、依頼主が書いたもの以外は仮置きです。
- KOKOIROメンタルケア協会の既存イラストは参考にしていますが、素材は使っていません
  （キャラクターは本リポジトリ内で描き起こしたSVG）。著作権は代表から許諾済みです。
