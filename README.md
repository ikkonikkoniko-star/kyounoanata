# きょうのいろ — 今日の色 きせかえツール

「今日はどんな自分でいたいか」を選ぶと、そう見せてくれる色を1つ提案し、
その色を身のまわりにどう取り入れるかの具体案を一緒に出すツールです。
色の意味を読ませるだけでなく、キャラクターに実際にその色を「着せる」ことで、
着たときのイメージが直感的につかめるようにしています。

**外部への通信はありません。** 文章はすべて固定で、APIキーもサーバーも要らない、
ビルド不要の静的サイトです。ファイル一式をどこかに置けばそのまま動きます。

## 画面

| ファイル | 内容 |
|---|---|
| `index.html` | 3つのVerへの入口 |
| `personal.html` | 個人Ver |
| `business.html` | ビジネスVer |
| `kids.html` | キッズVer |

3Verとも、POPなキャラクター表現（丸顔キャラクター＋吹き出し＋カラフル図形）は共通です。
差分はチップの文言・スロットの呼び名・言葉づかいのトーン・提案文だけで、
`assets/versions.js` にまとまっています。

チップは18色ぶん（1色につき1つ）。**どのチップがどの色になるかは固定**で、
判定はしません。キッズVerだけ `chipLabels` で言い回しをひらがなに差し替えています。

| | イラスト（左・中央・右） |
|---|---|
| 個人Ver | ハンカチ・Tシャツ＋デニム・バッグ |
| ビジネスVer | 腕時計・Tシャツ＋ジャケット・ペン |
| キッズVer | 靴下・Tシャツ＋クロップドパンツ・ハンカチ |

ゴールドとシルバーのときだけ、ハンカチを腕時計に差し替えます（金属色の布は絵として成立しないため）。

人物は男女どちらにも見えるように、髪は左右対称のまるい形、肩幅と胴はやや細めにしています。

結果は「色名＋hex」「一言」「取り入れ方（1枠）」の順で出ます。文言はすべて固定です。

| 行 | 中身 | どこで直すか |
|---|---|---|
| 一言 | きょうは○○のちからをかりてみましょう。 | `versions.js` の `resultFor` |
| 取り入れ方 1〜2文目 | 着る服に○○を取り入れてみたり、ハンカチなどの小物に○○を足してみましょう。 | `versions.js` の `suggestion`（Ver別） |
| 取り入れ方 3文目 | ○○は（色の意味） | `colors.js` の `meaning` |
| 取り入れ方 4文目 | （締めの一文） | `colors.js` の `closing` |
色が変わるのはトップスだけで、デニムとジャケットは固定の色です。

## 動かす

```
python3 -m http.server 8000
# → http://localhost:8000/
```

`index.html` をブラウザで直接開くだけでも動きます（外部への通信がないため）。

## 色のロジック

**色はチップを押した時点で決まります。** `assets/colors.js` の `feeling` と色が
1対1で結びついているだけで、判定も推論もしません。同じチップを押せば必ず同じ色・同じ文章が出ます。

色名は身近で、そのまま口に出せる名前だけにしています。表記はひらがな中心で、
カタカナでしか通じない色だけカタカナのままです。和色などの珍しい名前は入れていません。

| 気持ち | 色 | 気持ち | 色 | 気持ち | 色 |
|---|---|---|---|---|---|
| 積極的に動く | あか | 一人になりたい | ラベンダー | こつこつ努力 | ちゃいろ |
| チームワークを大事にしたい | オレンジ | 自分らしさ全開 | むらさき | 結果を出す | ゴールド |
| 楽しみたい | きいろ | 共感してほしい | あかむらさき | 自分の満足度上げたい | シルバー |
| 新しいことにチャレンジ | きみどり | 誰かを支えたい | ピンク | 自由に | しろ |
| ゆっくり過ごす | みどり | 目立たず | カーキ | 上品に | グレイ |
| なるようになる | みずいろ | しっかり考えたい | あお | プロ意識をもって | くろ |

| | |
|---|---|
| 色相順 | あか・オレンジ・きいろ・きみどり・みどり・みずいろ・あお・ラベンダー・むらさき・あかむらさき・ピンク |
| 土・金属 | カーキ・ちゃいろ・ゴールド・シルバー |
| 無彩色 | しろ・グレイ・くろ |

ゴールドとシルバーだけは単色だと金属に見えないので、`sheen`（照りのグラデーション）を持たせています。
`sheen` のある色は、見本・服・小物のすべてがグラデーションで塗られます。

パレットを増減するときは `assets/colors.js` の配列だけを直せば足ります。

## LINE公式アカウントで配る場合

外部通信もAPIキーもないので、公開できる場所（GitHub Pages など）にファイルを置き、
その URL をリッチメニューに設定すればLINEのアプリ内ブラウザで動きます。
LIFF は不要です（LINEログインやトークへの送信をするなら別途必要）。

## ファイル構成

```
assets/
  colors.js      18色パレット（気持ち・色名・hex・意味の表）とチップの組み立て
  character.js   Verごとのキャラクター・小物のSVG描画、色の濃淡計算
  versions.js    3Verの差分（質問文・キッズのチップ文言・取り入れ方の1〜2文目）と結果の組み立て
  app.js         画面の組み立てと操作
  style.css      3Ver共通のスタイル
```

## 未確定・これから詰めること

- **色の意味の文言**（`assets/colors.js` の `meaning`）は仮置きです。FTA色彩心理®︎に沿って詳細を厳選する予定。
- **キャラクターの見た目のバリエーション**（性別・髪型など）は未着手。
  `renderCharacter()` は Ver ごとに絵を出し分けるところまでは来ているので、
  同じVer内で複数の見た目を持たせるのが次の段階。
- **KOKOIROメンタルケア協会の既存イラスト**は参考にしていますが、素材は一切使っていません
  （キャラクターは本リポジトリ内で描き起こしたSVG）。実運用時は著作権の確認が別途必要です。
