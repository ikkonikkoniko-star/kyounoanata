# きょうのいろ — 今日の色 きせかえツール

「今日はどんな自分でいたいか」を選ぶと、そう見せてくれる色を1つ提案し、
その色を身のまわりにどう取り入れるかの具体案を一緒に出すツールです。
色の意味を読ませるだけでなく、キャラクターに実際にその色を「着せる」ことで、
着たときのイメージが直感的につかめるようにしています。

ビルド不要の静的サイトです。

## 画面

| ファイル | 内容 |
|---|---|
| `index.html` | 3つのVerへの入口 |
| `personal.html` | 個人Ver |
| `business.html` | ビジネスVer |
| `kids.html` | キッズVer |

3Verとも、POPなキャラクター表現（丸顔キャラクター＋吹き出し＋カラフル図形）は共通です。
差分はチップの文言・スロットの呼び名・言葉づかいのトーン・提案文だけで、
`assets/versions.js` にまとまっています。

| | チップ | イラスト（左・中央・右） |
|---|---|---|
| 個人Ver | 積極的に動く／ゆっくり過ごす／誰かを支えたい／眠たい | ハンカチ・Tシャツ＋デニム・バッグ |
| ビジネスVer | 会議で意見を通したい／落ち着いて商談したい／チームをまとめたい／初対面で好印象を持たれたい | 腕時計・Tシャツ＋ジャケット・ペン |
| キッズVer | げんきに あそびたい／のんびり したい／ともだちと なかよくしたい／ちょっと どきどき | 靴下・Tシャツ＋クロップドパンツ・ハンカチ |

人物は男女どちらにも見えるように、髪は左右対称のまるい形、肩幅と胴はやや細めにしています。

結果は「色名＋hex」「一言」「取り入れ方（1枠）」の順で出ます。
一言は `きょうは○○のちからをかりてみましょう。` の決まり文句で、モデルには作らせません。
取り入れ方は枠を分けず、ひとつづきの文章で「服への取り入れ方 → 小物への取り入れ方 →
その色の意味と力 → 前向きな締め」の順に書かせます。色の意味はプロンプトに一緒に渡すので、
`assets/colors.js` の `meaning` を直せば生成される文章もそれに沿います。
色が変わるのはトップスだけで、デニムとジャケットは固定の色です。

## 動かす

```
python3 -m http.server 8000
# → http://localhost:8000/
```

APIキーなしでも、18色のローカル辞書で最後まで動きます。
Claude API を使う場合は、`file://` で直接開くとCORSで弾かれるので、上のように配信してください。

## 色のロジック

1. **Claude API**（`assets/api.js`）— 選ばれたチップから色名と取り入れ方を
   JSONで生成させます。色名は18色パレットから選ばせ、**hexは必ずローカルのパレット側の値**を使うので、
   パレット外の色が出ることはありません。
2. **ローカル辞書**（`assets/colors.js`）— APIキー未設定・通信失敗・JSONを読めなかった場合の
   フォールバック。18色それぞれのキーワードと入力文を突き合わせてスコアが最大の色を選びます。
   このときは結果カードに「オフライン辞書で表示しています」と出ます。

色名は身近で、そのまま口に出せる名前だけにしています。表記はひらがな中心で、
カタカナでしか通じない色だけカタカナのままです。和色などの珍しい名前は入れていません。

| | |
|---|---|
| 色相順 | あか・オレンジ・きいろ・きみどり・みどり・みずいろ・あお・ラベンダー・むらさき・あかむらさき・ピンク |
| 土・金属 | カーキ・ちゃいろ・ゴールド・シルバー |
| 無彩色 | しろ・グレイ・くろ |

パレットを増減するときは `assets/colors.js` の配列だけを直せば、プロンプトの色数表記も辞書マッチも追随します。

### モデル

`assets/api.js` の先頭 `KI.MODEL` の1行だけです。現在は `claude-sonnet-4-6`。

`claude-sonnet-4-6` は構造化出力（`output_config.format`）に対応していないため、
プロンプトでJSONを指示し、コードブロックや前置きが付いていても取り出せるパーサを通しています。
`claude-sonnet-5` や `claude-opus-5` など対応モデルに書き換えると、
18色をenumにしたスキーマが自動で付き、色名の揺れがAPI側で保証されます。

## APIキーの扱い（重要）

ブラウザから `api.anthropic.com` へ直接 fetch する構成のため、
`anthropic-dangerous-direct-browser-access` ヘッダを付けています。
キーは画面下の「APIキーの設定」から入れると、その端末の `localStorage` にだけ保存されます。

**この構成ではキーがページを開いた人に読み取れます。** 手元での試作・デモ用と考えてください。
不特定多数に公開する場合は、キーをサーバー側で預かって中継する構成に変える必要があります。

## ファイル構成

```
assets/
  colors.js      18色パレット＋キーワード辞書＋辞書マッチ
  character.js   Verごとのキャラクター・小物のSVG描画、色の濃淡計算
  versions.js    3Verの差分（チップ・トーン・想定アイテム・フォールバック提案文）
  api.js         Claude API 呼び出しとJSON取り出し
  app.js         画面の組み立てと操作
  style.css      3Ver共通のスタイル
```
