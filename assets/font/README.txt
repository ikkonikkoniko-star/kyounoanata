============================

配布元：https://fonts.google.com/specimen/M+PLUS+Rounded+1c
ライセンス：SIL Open Font License 1.1（同じ場所の OFL.txt が全文）

このライセンスは、サイトに入れて使うこと・配ることを認めています。
字体だけを売ることはできません。

ファイル
  mplus-rounded-400.woff2 … ふつうの太さ
  mplus-rounded-700.woff2 … 太字
  mplus-rounded-900.woff2 … いちばん太い（見出し・ロゴ）

小さくするために、このサイトで使っている文字だけを抜き出してあります
（ひらがな・カタカナ・英数字・記号はぜんぶ、漢字はいま使っているものだけ）。

■ 新しい漢字を文章に足したとき
その漢字だけ、字体がそろわないことがあります。
そのときは字体ファイルを作り直す必要があるので、知らせてください。

■ 外部との通信について
字体はこのサイトの中に置いてあります。外のどこにも取りに行きません。
