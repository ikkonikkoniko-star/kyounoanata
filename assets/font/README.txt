この中の字体ファイルについて
============================

字体：Rounded M+ 1c（M PLUS Rounded 1c）
作者：The Rounded M+ Project Authors
配布元：https://fonts.google.com/specimen/M+PLUS+Rounded+1c
ライセンス：SIL Open Font License 1.1（同じ場所の OFL.txt が全文）

このライセンスは、サイトに入れて使うこと・配ることを認めています。
字体だけを売ることはできません。

ファイル
  mplus-rounded-regular.woff2   … 本文
  mplus-rounded-medium.woff2    … 少し太いところ
  mplus-rounded-extrabold.woff2 … 見出し・ロゴ

いちばん太い Black は使っていません（重たく見えるため）。
全体をもう一段太く／細くしたいときは、この3つを
Medium・Bold・Black（太く）や Light・Regular・Bold（細く）に
入れ替えれば変わります。

■ どこで使っているか
サイト全体です。

小さくするために、このサイトで使っている文字だけを抜き出してあります
（ひらがな・カタカナ・英数字・記号はぜんぶ、漢字はいま使っているものだけ）。

■ 新しい漢字を文章に足したとき
その漢字だけ、字体がそろわないことがあります。
そのときは字体ファイルを作り直す必要があるので、知らせてください。

■ 外部との通信について
字体はこのサイトの中に置いてあります。外のどこにも取りに行きません。
